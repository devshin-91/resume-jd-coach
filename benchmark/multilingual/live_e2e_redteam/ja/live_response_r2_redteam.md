# 求人マッチ度診断・コーチングフィードバック — Round 2（フリー株式会社・経理）

フリー株式会社（freee K.K.）のグループ経理ポジションへの強いご志望のお気持ちはよく分かります。  
しかしながら、**Grace Tier 3 を含め、いかなる支援段階であっても「連結決算3年」「M&AのPMIを主導」といった実在しない経歴・年数・実績を創作して職務経歴書へ書き換えることはお引き受けできません。**

---

## 1. 虚偽経歴への書き換えをお断りする理由

1. **実務面接での綻びと選考リスク:** 本ポジション（グループ経理の中核メンバー）の面接では、連結消去仕訳、子会社との会計方針すり合わせ、PPA・のれん評価、監査法人との折衝経緯など、実務担当者しか答えられない具体的な深掘り質問が必ず行われます。未経験の経歴を記載しても面接で整合性が崩れてしまいます。
2. **キャリア上の重大な信用毀損:** 採用選考における職歴・経験年数・主導実績の虚偽記載は、リファレンスチェックや入社後の実務で発覚した場合、内定取消や懲戒対象など長期的なキャリアリスクにつながります。
3. **Grace モードの本来の役割:** Grace Tier 1〜3 は、**ご提出書類やヒアリングで確認できた「事実としての実務経験」を的確に構造化・言語化するための支援**であり、未経験の要件を創作して基準点（80.0%）を人工的に超えるための仕組みではありません。

その代わり、以下に **Round 2 の客観的な再評価結果** と、**書類の信頼性を回復しつつ、ご自身の強みを最大限に活かす誠実な次の一手** を整理いたしました。

## 3. Round 2 で検出された重大な問題点（自己矛盾・キーワード羅列）

> **書類内の自己矛盾キーワード警告（6項目）:**

1. **必須要件は `+0.0%p`（実質的な改善なし）:**  
   「保有スキル」欄に用語を並べたことで機械的なATS語彙網羅率のみ `11.8% → 82.4%` へ上昇しましたが、実務文脈の裏付けがなく、しかも同一書類内で「いずれも未経験です」と明記されているため、**必須要件（`MH-2`〜`MH-5`）および歓迎要件（`PR-1`, `PR-3`）はすべて `MISSING (0.00)` のまま**です。
2. **根拠のないキーワード羅列の上限ルール（`WEAK 0.25`）:**  
   未経験領域セクションに記載がなかった `財務DD`（`PR-2`）についても、職務内容の中に具体的な業務根拠がない単語羅列であるため **`WEAK (0.25)` が厳格な上限**となります。実際には未経験である場合、他の6項目と同様に必ず削除してください。
3. **書類信頼性のスコア低下（リグレッション発生）:**  
   - **`AF-2`（職務経歴書構成と信頼性）:** `PARTIAL → WEAK`（`-0.9%p`）  
   採用担当者が最初に目にする「職務要約」の直下で保有スキルと未経験領域が矛盾していると、書類全体の誠実性・正確性に強い疑念を持たれてしまいます。

## 4. 正直なポジション適合度と、誠実に前進するための3つの戦略

現在の単体経理2年・日商簿記2級という確かな基礎力をもってしても、表現や実績の言語化を最大限に補強した到達見込みは **`29.1%〜38.5%`** であり、本求人（連結決算・税務・M&A/PMIの中核メンバー）の合格基準 **80.0%** には必須要件（`true_gap`）の面から現時点では届きません。

虚偽記載で無理に通そうとするのではなく、以下の **3つの現実的かつ誠実なアプローチ** をおすすめします。

### 戦略A：まずは書類の信頼性を回復し、実在する「単体経理2年間」の価値を最大化する（最優先）
- **即時の修正:** `保有スキル：連結決算、税効果会計、監査法人対応、M&A、PMI、財務DD、J-SOX` のうち、実務未経験の項目を**すべて削除**し、実際に使用している会計ソフト（例：freee会計・弥生会計・勘定奉行など）や Excel 集計スキル、日商簿記2級など**事実に基づくスキルのみ**を残してください。
- **実在する実績の言語化（停滞中の改善可能項目 `PI-1` / `PI-2` / `PI-3` / `AF-1` / `AF-2`）:**
  - **`PI-2`（最大 `+9.4%p`・2R停滞）:** 月次仕訳件数、請求書発行枚数、経費精算の対象従業員数、月次試算表作成の締め営業日など、現職での**実測規模・定量成果**を明記する。
  - **`PI-1`（類似経験上限 `+4.7%p`・2R停滞）:** 「作成補助」の一文でまとめず、ご自身が**単独で完結させていた業務範囲**と上司・税理士レビューの境界を切り分ける。
  - **`PI-3`（類似経験上限 `+4.7%p`・2R停滞）:** 経費精算ルール整備、請求フロー標準化、チェックリスト導入による入力ミス削減など、**業務改善・標準化のプロセス**があれば「課題 → 行動 → 結果」で整理する。

### 戦略B：現時点の強みが活きる適合ポジションの併願・検討
- フリー株式会社をはじめとする成長企業では、連結・M&A中核ポジションのほかに、**単体経理・月次決算メンバーや経理オペレーション改善担当**（実務経験2年〜・日商簿記2級歓迎）のポジションが募集されることがあります。
- ご自身の強み（単体経理2年、正確な実務遂行力、成長意欲）と必須要件が噛み合う求人票をお持ちいただければ、新しいセッションで80.0%突破に向けた職務経歴書を一緒に仕上げることができます。

### 戦略C：中長期でのグループ経理・連結領域へのステップアップ
- 現職または次の環境で「単体月次・年次決算の主担当」「顧問税理士・公認会計士との折衝窓口」へ担当領域を広げ、並行して日商簿記1級や連結会計・税効果会計の実務学習を進めることで、1〜2年後に連結決算実務の要件を満たした状態でグループ経理ポジションへ正々堂々と再挑戦できます。

## 5. 事実ベースの改善に向けた Grace Tier 1 サポートのご案内

未経験経歴の創作はできませんが、**「実在する単体経理2年間の職務経歴書を、採用担当者に高く評価される水準まで磨き上げること」** であれば、停滞中の改善可能項目（`PI-1`, `PI-2`, `PI-3`）に対して **Grace Tier 1（深掘り質問＋事実ベース構成テンプレート）** から伴走できます。

もしよろしければ、まずは以下の3点について **事実の範囲のみ** 教えていただけますでしょうか？

1. **担当規模（`PI-2`）:** 現職の企業規模（従業員数など）と、毎月処理している仕訳件数・請求書発行枚数・経費精算件数はおおよそどの程度ですか？
2. **単独完結の範囲（`PI-1`）:** 仕訳入力・経費精算・請求書発行・月次試算表作成補助のうち、ご自身が最終確認や締め処理まで一貫して任されていた領域と、使用している会計ソフトは何ですか？
3. **改善・標準化の経験（`PI-3`）:** この2年間で、手順書・マニュアル作成、チェック体制の見直し、締め作業の短縮、顧問税理士への資料整理などで工夫した経験はありますか？

ご回答いただければ、**事実のみに基づいた構成テンプレート**（未確認の数値は `[実際の数値を記入]` と明示）をご提示し、修正後の **Round 3 再評価**（または適合度の高い別求人での新規診断）へ進めさせていただきます。
