# 정민호 이력서 — 한국신용데이터 Data Analyst 지원

## 요약
5년 5개월간 BigQuery SQL·Python·Tableau 기반으로 현업 요청을 KPI 과제로 재정의하고, 통계적 A/B 테스트와 LLM 기반 셀프서비스 분석 자동화로 실제 CRM 전환율·리텐션을 끌어올린 데이터 분석가입니다.

## 경력
### 리테일인사이트 (2021.05 ~ 현재, 시니어 데이터 분석가 / 5년 5개월)
- **현업 KPI 과제 재정의 및 CRM 성과 개선:** 마케팅팀의 단순 조회 요청을 '이탈 위험군 재구매율 제고' KPI 과제로 재정의하고, BigQuery SQL로 결제·로그·회원 원천 테이블을 통합한 분석용 데이터 마트(12개 테이블) 직접 설계·구축.
- **통계적 가설 검정 및 A/B 테스트:** 마케팅 CRM 푸시 캠페인(N=12만)에서 Mann-Whitney/카이제곱 검정 및 다중비교 보정으로 최적 세그먼트 도출 → 클릭률 +4.2%p, 전환율 +1.8%p, 30일 리텐션 +3.1%p 개선.
- **LLM 기반 셀프서비스 분석 도구 배포:** Claude/OpenAI API + Streamlit으로 비개발 현업(마케팅·영업 25명)이 자연어로 KPI를 조회하는 셀프서비스 도구를 배포해 반복 추출 요청 68% 감소(주 31건 → 10건).
- **재사용 가능한 코드 및 데이터 보안:** Git PR 코드 리뷰 및 표준 SQL 템플릿 운영, 고객 결제·개인정보 가명처리(PII 마스킹) 준수.
- **현재 미경험 영역(정직 표기):** Spark 분산 처리 및 PyTorch/Scikit-learn 머신러닝 모델 프로덕션 배포는 아직 미경험이며, SQL·통계 실험 중심으로 기여 가능.
## 기술 스택
SQL(BigQuery), Python(pandas, scipy, statsmodels), Tableau, Git, LLM API
