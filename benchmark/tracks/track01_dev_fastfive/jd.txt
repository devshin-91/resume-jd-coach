기획서를 기다리기보다 고객 최접점에서 문제를 먼저 찾아 정의하고, 백엔드부터 화면까지 직접 만들어 실제 사용 환경에서 해결될 때까지 책임지는 개발자를 찾습니다.
제출서류: 이력서와 포트폴리오("무엇을 만들었는지"보다 "어떤 문제를 발견해서 어떻게 해결했는지"가 드러나면 좋습니다) (PDF 형식)

[주요업무]
1. 시스템을 넘나드는 구현
- 출입, 인증, 예약, 멤버십, 결제·커머스 등 여러 서비스에 걸친 기능을 끝까지 구현
- 백엔드 API뿐 아니라 필요하면 웹 화면, 앱 화면, 어드민 화면까지 직접 제작
- 토스 페이스패스, Salesforce 같은 외부 파트너 API 연동
- 출입 게이트, 회의실 조명 등 IoT 디바이스 제어 이벤트 기반 시스템
2. 문제 발견과 정의
- 지점 운영팀·CS·멤버 문의에서 반복되는 불편을 찾아 기술 문제로 정의
- 로그, 모니터링, 운영 데이터를 직접 분석해 원인 규명
- 해결 방향을 설계 문서로 정리하고 기획·운영팀과 범위 합의
3. 운영과 검증
- 신규 지점·신규 기능 파일럿을 현장과 함께 설계·검증
- 장애와 데이터 사고 대응 및 재발 방지책 반영
- 배포 후 실제 환경 동작 확인 및 운영팀 활용 가이드 정리

[자격요건]
- 실제 사용자가 있는 서비스를 운영 환경에 배포하고 유지보수해 본 경험 (경력 4년 이상 또는 이에 준하는 실무 경험)
- 기능 하나를 문제 정의, 설계, 구현, 배포, 검증까지 처음부터 끝까지 맡아 본 경험

- 처음 보는 코드베이스와 시스템을 코드·로그·데이터를 직접 파고들어 이해할 수 있는 분
